# CareTV

CareTV is a way for a family member or caregiver to control a television for someone who cannot
reliably use a remote.

The goal is simple: make it possible to start shows, videos, playlists, or local media from a
dashboard, while a small Windows computer connected to the TV handles the actual playback.

I made this because normal streaming apps assume the person watching can navigate menus, recover
from popups, switch inputs, log in again, or fix playback when something gets stuck. That is not
always true. CareTV is meant to move those chores to someone who can help remotely, without needing
the viewer to touch anything.

This is still a prototype, not a polished product. It currently focuses on proving the core idea:
remote control, media queues, local playback, basic streaming support, and appliance status.

For setup, architecture, deployment notes, and current limitations, see the
[technical README](docs/technical-readme.md).
